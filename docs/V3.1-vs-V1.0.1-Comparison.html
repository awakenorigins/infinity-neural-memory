Ưu điểm

🏆 Kết luận — Xóa V3.1, giữ V1.0.1

V3.1 là tài liệu protocol rất tốt nhưng không phải engine thật — nó wrap neural-memory bên ngoài và không enforce những gì nó hứa.

V1.0.1 là engine thật, tự chứa, trung thực — mọi tính năng chạy được, test được, prove được. Thiếu MCP wrapper thì build thêm được. Thiếu graph relations thì V2.0 sẽ có.

Giữ V3.1 lại chỉ tốn context tokens — 724 dòng SKILL.md load mỗi session mà phần lớn là docs, không phải code chạy được.
